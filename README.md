# AI LinkedIn Profile Generator

A beginner-friendly Streamlit prototype that generates a LinkedIn headline, About section, skills list, and next-step suggestions from user inputs.

## Run
1. Install Python 3.10 or newer.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`

## Limitation
This starter version uses templates and simple rules, not a live AI model or LinkedIn integration. It creates draft text only. Verify and personalise the result before publishing.
